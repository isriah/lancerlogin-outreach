# LancerLogin Outreach plugin v1.3.1

This release fixes two things in the **Create Outreach activity** and **Edit Outreach activity** dialogs: Tab now moves through each part of the event time fields in order, and the label checkboxes take much less room. Nothing else changes.

It works with the same LancerLogin Core releases as v1.3.0: Core 2.1.0-beta.7 or later (`lancerlogin.core` `>=2.1.0-beta.7 <3.0.0` with `@lancerlogin/module-sdk` `^1.5.0`). It adds no migration, and backups still use Outreach backup version 5.

## Bugs fixed

- In **Event start time** and **Event end time**, Tab now moves from the hour to the minutes to AM/PM. Before, typing an hour such as 9 and pressing Tab skipped the minutes, and typing the minutes and pressing Tab skipped AM/PM. Shift+Tab, the arrow keys and the time picker work as before.
- The **Outreach labels (optional)** checkboxes sit side by side in a compact grid instead of one tall row each, so the dialogs are much shorter. Each choice is as easy to click or tap as before, and long label names wrap.
