# LancerLogin Outreach plugin v1.1.0

This release lets other plugins record team support in Outreach. A plugin such as Guest Visits can find a supported team by number and program, add the team when it is not listed yet, and create the Team Support activity for a visit, but only after an Administrator grants that access in **Settings > Modules > Module access**. Outreach keeps its own data rules: it never adds a second Team Support activity for the same team and date, and it does not record support for an archived team. It needs LancerLogin Modular 2.0.0-beta.15 or later. Existing activities, participation entries and settings are unchanged, and the update runs no database change.

## Bugs fixed

None.

## Features added

- Other plugins can find supported teams, add a supported team and create a Team Support activity through Outreach, with an Administrator's grant or for a signed-in user who can manage Outreach. Each request is safe to repeat, refuses archived teams and is recorded in the audit log with the plugin that made it.

## Features removed

None.
