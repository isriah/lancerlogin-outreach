# LancerLogin Outreach plugin v1.4.0

Members can now check their own Outreach participation from Discord. **`/outreach-report`** replies privately with the member's counted hours, activities and entries since the Outreach reporting start date, broken down into Event, Team Support and Other Service, an all-time total, their five most recent entries with receipt references, and how many of their correction requests Staff have not reviewed yet.

It works with the same LancerLogin Core releases as v1.3.x: Core 2.1.0-beta.7 or later (`lancerlogin.core` `>=2.1.0-beta.7 <3.0.0` with `@lancerlogin/module-sdk` `^1.5.0`). It adds no migration, and backups still use Outreach backup version 5. Core registers the new command with the Discord server automatically after the update.

## Bugs fixed

None.

## Features added

- **`/outreach-report`** in the Discord server configured in **Settings > Integrations**, for members whose Discord account is linked to exactly one active roster member. It takes no options, and only the member sees the reply.
  - With an **Outreach reporting start date (operational baseline)** set in **Settings > Outreach > General**, the reply starts with hours, distinct activities and entries since that date, one line per activity type that has participation, then an all-time line. Without a start date it gives all-time totals by type. Hours are total minutes divided by 60 to two decimals, as the Outreach page shows them.
  - **Recent participation** lists up to 5 of the latest counted entries, newest first, with the service date, activity, hours and the full receipt reference to paste into `/outreach-correction receipt:`.
  - Open correction requests are counted, with a reminder that totals change only after Staff review.
  - Voided entries and private task notes are never shown. Activity titles lose Discord formatting characters, and the reply stays under Discord's 2,000-character limit.
  - A Discord account that is not linked to exactly one active roster member is told to use `/pair` with their member ID or ask an Operator to check their roster link.
  - The command reads everything it shows in one D1 batch, well within the Workers Free plan's limits.

## Features removed

None.
