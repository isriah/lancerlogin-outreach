# LancerLogin Outreach plugin v1.3.0

Staff can import Outreach activities from a CSV file, Events publish automatically to Discord and Google Calendar each on its own switch, and Outreach reports have their own reporting start date. **Import CSV** on the Outreach page imports up to 200 activities from a CSV file or pasted spreadsheet rows, with a preview of every row before anything is saved. **Settings > Outreach > General** has one automatic publication switch per destination, keeps published Events in sync when they are edited, and shows **Outreach reporting start date (operational baseline)**.

This release needs LancerLogin Core 2.1.0-beta.7 or later (`lancerlogin.core` `>=2.1.0-beta.7 <3.0.0` with `@lancerlogin/module-sdk` `^1.5.0`), the first Core with module SDK 1.5.0. It does not install on Core 2.1.0-beta.6 or earlier: composition refuses it before an installation build or web update starts, so update Core first. It adds migration 0002, which replaces the single automatic publication setting with one per destination. Installations that had automatic publication on get both switches on. Entire-installation backups now use Outreach backup version 5. Older backups still restore, but a backup made with this release cannot be restored into an installation that runs an older Outreach release.

## Bugs fixed

- A Discord rate limit no longer shows a "wait" message that never counts down. A rate limit now waits as long as Discord asks, from a minute to an hour, without counting a failed attempt.
- Event publication no longer gives up after 6 attempts. Failed deliveries retry with a backoff that doubles from a minute up to an hour, as meeting calendar sync does.
- Event publication stays within the Workers Free plan's limits: the queue delivers at most 5 Events a run.
- Editing an Event that is already published updates it there even when automatic publication is off.
- The Discord publication button uses Discord's current logo.
- The clock face on the public form, **Edit participation**, manual participation and corrections has 12 at the top instead of 1. Clicking, typing and AM/PM work as before.

## Features added

- **Import CSV**, just left of **+ Create activity** on the Outreach page (below the month navigation on phones), imports up to 200 activities of any type, for Admins and Operators. **Download template** gives the columns with synthetic examples, and **Preview activities** shows every row before anything is saved. Rows with a problem are listed with their reason and skipped. Rows that match an existing activity can be skipped or updated, one by one or all at once. Imported Events that have not ended yet are queued to the destinations whose automatic switch is on.
- **Publish Events to Discord automatically** and **Publish Events to Google Calendar automatically** in **Settings > Outreach > General**, each off by default and disabled, with a link to **Settings > Integrations**, until that destination is set up. Under each switch the card shows the deliveries waiting, those that need another attempt and the latest problem.
- **Publish upcoming Events** queues up to 100 active Events that have not ended yet to each destination that is on. It is offered once, with a confirmation, when a switch is turned on.
- Saving or publishing an Event makes its first delivery attempt right away. An Event's publication menu says when a failed delivery retries, and a refusal that repeats, such as Discord's limit of 100 scheduled events, waits for **Retry**.
- **Outreach reporting start date (operational baseline)** in **Settings > Outreach > General**. Outreach reports use it for the Operational baseline period, separately from Attendance's date, and the card warns when the date is in the future. **Reporting window in days** now says it does not affect reports.

## Features removed

- The single **Automatically publish Events** switch, replaced by the two per-destination switches. The `/admin/hours/publication-settings` route still works and sets both.
- Support for LancerLogin Core releases before 2.1.0-beta.7.
