# LancerLogin Outreach plugin v1.0.0

This first standalone release packages Outreach Participation as LancerLogin's first official module plugin. It contains the same Outreach that was part of LancerLogin 2.0.0-beta.11, so existing installations keep their activities, participation entries, settings, permissions, saved reports, publications and walkthrough progress unchanged.

## Bugs fixed

None.

## Features added

- Outreach is available as an official plugin for LancerLogin Modular 2.0.0-beta.11 and later 2.x releases, included in every installation build by default.
- Outreach adopts the database tables LancerLogin already created, so the change runs no database update on an existing installation.
- A new installation creates Outreach's default settings and the Event, Team Support and Other Service activity types when an Administrator first enables it.

## Features removed

None.
