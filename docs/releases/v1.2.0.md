# LancerLogin Outreach plugin v1.2.0

Members can now log outreach time that has no Staff-created activity. The public form starts by asking **What are you logging?**: a **Scheduled activity** Staff created, as before, **Team support** or **Other service**. Team support and Other service take a service date and a number of minutes, with no start or end time, and count right away. When a member adds a team that is not on the supported teams list yet, the form checks the team number with FIRST and fills in the team's name. Staff review the teams members add in **Settings > Outreach > Supported teams**.

This release needs LancerLogin Core 2.1.0-beta.3 or later (`lancerlogin.core` `>=2.1.0-beta.3 <3.0.0` with `@lancerlogin/module-sdk` `^1.2.0`), the first Core with the shared FIRST connection in **Settings > Integrations > FIRST**. Older Core releases are no longer supported. It adds migration 0001, which records which supported teams members added and whether an entry has start and end times or only minutes. Existing teams count as added by Staff, and existing entries keep their start and end times. Entire-installation backups now use Outreach backup version 4. Older backups still restore, but a backup made with this release cannot be restored into an installation that runs an older Outreach release.

## Bugs fixed

None.

## Features added

- **Team support** on the public form. The member chooses a supported team, or **My team is not listed - add it** and enters the team number, program and team name, then the service date, minutes and an optional note. The entry joins that team's Team Support activity for the date, which Outreach creates when there is none. A new team that matches a listed team's number and program joins the listed team instead of adding a second one.
- **Other service** on the public form, for service such as STEM tutoring: a description, the service date and minutes. The entry joins the Other Service activity with that description on that date, which Outreach creates when there is none.
- Team support and Other service entries count right away, from 1 to 1,440 minutes on a date inside the reporting window, and Staff can edit or void them like any other entry. Staff screens show **Duration only** where other entries show start and end times, **Edit participation** and correction resolution ask for **Minutes** instead, and reports show N/A for their start and end times.
- New team numbers are checked with FIRST through LancerLogin's shared FIRST connection. When FIRST finds the team, its name fills in and locks, with "Name from FIRST (2026 season)." below it. When FIRST has no such team, the form warns, and the member can still add the team with the name they type. When FIRST cannot answer, for example because no FRC or FTC credential is saved in **Settings > Integrations > FIRST**, the form says nothing and the member types the name. Outreach checks again when the entry is sent and keeps FIRST's name when FIRST finds the team. It never refuses an entry because FIRST is unavailable or has no such team.
- Teams members add appear in **Settings > Outreach > Supported teams** marked **Added by a member**. The **Added by** filter shows **Members, not yet reviewed**, and **Mark reviewed** clears the mark once Staff have checked the team. Staff can also edit the team or archive a duplicate.
- Each choice on the public form fits on a laptop screen without scrolling, and Team support's note and Other service's description each have their own line.

## Features removed

- The **Staff sign in** link at the bottom of the public form. Staff sign in from the dashboard as before.
- Support for LancerLogin Core releases before 2.1.0-beta.3.
